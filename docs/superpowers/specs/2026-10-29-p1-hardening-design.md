## 范围和选择

沿用审查中已经提出并获用户授权的修复方向。选择分组件最小修复并增加可运行回归，而非整体框架重写或只更新简历描述。

1. 身份和数据：Gemma 缓存键含 userId；聊天请求必须验证会话归属；注册/登录及消息落库参数绑定；密码使用 OpenSSL PBKDF2 加盐哈希，明确旧明文记录兼容迁移；删除 API Key 日志。
2. 生命周期和并发：HTTP 请求弱引用连接并完整 reset；Session 存储/对象/随机数同步；连接池检查独占连接、失败容量可恢复、检查线程可停止。
3. 对话：MCP 临时上下文只在请求副本内存在；成功后提交正式问答；非增量答案也发送 SSE 内容；错误与完成互斥。
4. 本地模型：限定缓存数量与过期时间，内存预算；模型路径和 prompt token 预算前置验证，云端可在没有 Gemma 文件时启动。对第三方内核任意 abort 的完全隔离不作未验证承诺。
5. 消息：MQ 按 fd 管理 Channel，在所属 loop 注销并延迟销毁；持久消息及 publisher confirm，确认之前保留未决消息；明确入队拒绝。消费失败不得无条件 ACK；结构化消息参数化落库，稳定 messageId 和唯一索引支持重投幂等。保留旧数据，迁移脚本不自动对真实数据库执行。
