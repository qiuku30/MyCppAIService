Run `python3 tests/p1/integration_compile/run.py` from the repository root. It compiles the real AIHelper, strategy, config, and tools sources with `-fsyntax-only`, plus an interface probe instantiating ChatExchange persistence against the real MysqlUtil template and using SecureId.

The script requires actual nlohmann JSON headers at `/private/tmp/mycpp-p1-deps/nlohmann/json.hpp` and OpenSSL headers under `/opt/homebrew/opt/openssl@3/include`; override their roots with `JSON_INCLUDE` and `OPENSSL_PREFIX`. Curl uses the compiler's installed system headers. MySQL and AMQP/muduo use the neighboring bounded fixture ABIs, so this catches C++/JSON/interface errors without contacting external services. It does not establish runtime behavior, actual MySQL/AMQP/muduo ABI compatibility, Gemma model validity, or a complete application build/link.
